# Prompt 02 — Positioning Strategy & Information Architecture

Paste everything below the line into your coding agent.

---

Read `docs/brief.md` and `CLAUDE.md`. This phase produces strategy documents only — no code changes yet.

Using `docs/brief.md`, write `docs/strategy.md` covering:

- Market positioning statement (how this professional/studio should be perceived vs. competitors listed in the brief)
- Competitive differentiation (2-3 concrete points, grounded in the brief's differentiators, not generic claims)
- Target audience psychology — what this audience is skeptical of, what earns their trust, what makes them enquire
- Value proposition, sharpened into a single sentence usable as the homepage headline
- Authority-building framework (which credentials/experience/awards from the brief to foreground and where)
- Trust-building system (which trust signals appear, and on which pages)
- Commercial strategy (how the primary and secondary CTAs map to the audience's buying journey)

Then write `docs/sitemap.md` covering:

- Complete sitemap matching the routes scaffolded in Phase 01
- Primary and secondary navigation structure
- One-paragraph user journey per key audience segment (from landing to enquiry)
- The engagement funnel — what should happen on each page to move a visitor toward the primary CTA
- Content hierarchy for each page (what appears above the fold vs. below)

Base every claim on `docs/brief.md`. Where the brief doesn't specify something needed here, state the assumption explicitly in the document rather than inventing unlabeled facts. End with a summary of key strategic decisions made.

- Every assumption the agent made is clearly labeled, not stated as fact.
- The sitemap in `docs/sitemap.md` covers every page you actually need — add anything missing now, before code exists.
