# Step 0 — Fill the Brief (do this yourself, don't paste this into the agent)

Before pasting anything into Claude Code:

1. Open `docs/BRIEF-TEMPLATE.md`.
2. Fill in every field you can. It's fine to leave a few blank if genuinely not applicable — the agent will flag gaps and use clearly-labeled placeholders instead of inventing facts.
3. Save the completed file as `docs/brief.md` (same folder, drop `-TEMPLATE` from the name).
4. Open a terminal in this project folder and start your coding agent (e.g., run `claude` for Claude Code).
5. Confirm the agent can see `CLAUDE.md`, `docs/brief.md`, and the `skills/` folder — ask it to list them if unsure.

Once `docs/brief.md` exists, move to `prompts/01-project-scaffold.md` and start pasting prompts in order, one at a time, letting each phase complete before starting the next.
