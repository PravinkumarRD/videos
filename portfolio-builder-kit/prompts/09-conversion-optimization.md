# Prompt 09 — Conversion Optimization

Paste everything below the line into your coding agent.

---

Read `docs/strategy.md` (commercial strategy section) and `src/content/brief.js` for the primary/secondary CTAs and lead magnet.

Audit and strengthen conversion mechanics across the whole site built so far:

1. Verify every major page (Home, About, Services, Work, Case Study, Testimonials, Blog, Contact) has at least one meaningful, contextually relevant CTA — not just a repeated header button. Add one where missing.
2. Review CTA placement/hierarchy per page against `docs/strategy.md`'s engagement funnel — primary CTA should always be the visually dominant action; secondary CTA present but subordinate.
3. Strengthen the Contact page's lead qualification: if the brief implies multiple engagement types (e.g., different service tiers or project sizes), add a lightweight qualifying field/step to the form so incoming leads self-segment, without adding friction that would suppress simple enquiries.
4. If a lead magnet exists in the brief, ensure it has a genuine capture point (not just mentioned in passing) — e.g., a dedicated section or modal with its own form using the same Action pattern from Phase 07.
5. Add objection-reduction elements near key CTAs where appropriate (e.g., "no obligation," response-time expectation, or a relevant trust signal) — grounded in what's actually true per the brief, never fabricated guarantees.
6. Double check social proof (testimonials, results, logos) is distributed across the funnel, not only clustered on the homepage.

End with a short list of every conversion point on the site and what it asks the visitor to do.

---

**Before moving to Prompt 10, check:**
- Read the final conversion-point list the agent gave you — does every major page actually appear on it?
- Any "objection reduction" copy near a CTA is something you'd actually be comfortable promising a real client.
- The lead magnet (if you have one) is genuinely easy to find, not buried.
