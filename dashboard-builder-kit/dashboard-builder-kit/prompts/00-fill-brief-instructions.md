# Step 0 — Fill the Brief (do this yourself, don't paste this into the agent)

1. Open `docs/BRIEF-TEMPLATE.md`.
2. Fill in every field you can — industry, users, KPIs, data domains, required pages/features, roles, compliance needs, etc. It's fine to leave a few blank; the agent will flag gaps and use clearly-labeled placeholders instead of inventing facts.
3. Save the completed file as `docs/brief.md`.
4. Start your coding agent in this project folder (e.g., `claude` for Claude Code).
5. Confirm the agent can see `CLAUDE.md`, `docs/brief.md`, and the `skills/` folder.

Then move to `prompts/01-project-scaffold.md` and paste prompts in order, one at a time, letting each phase complete before starting the next.
